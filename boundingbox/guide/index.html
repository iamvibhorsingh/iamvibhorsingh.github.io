Open BoundingBox map MCP setup and examples

Draw and export a bounding box

A bounding box is the rectangular extent of an area. It’s useful for limiting a GIS query, sharing an area of interest, or selecting the part of a map you want to export.

Draw or paste an extent

  1. Open BoundingBox and zoom to your area.
  2. Choose the rectangle tool or press R. Drag from one corner of the area to the opposite corner.
  3. For exact coordinates, choose Enter coordinates. Paste four longitude/latitude values in west, south, east, north order and select Add.

Open the example extent around The Hague
4.296,52.074,4.328,52.087

Use the box in an OGC API request

Select Copy CSV under Box Formats, then use the four values as the bbox query parameter on your collection’s items endpoint.

/collections/your-collection/items?bbox=4.296,52.074,4.328,52.087

The example uses longitude, latitude in degrees. Copy GeoJSON Polygon gives you a geometry you can save to a .geojson file and open in QGIS. Copy WKT gives you the equivalent rectangle as text.

Get a projected extent

Enter a coordinate reference system in the EPSG field, then select its tab in the coordinate panel and use Copy Box Projected. The Box Formats buttons provide WGS84 formats. Use the display controls to adjust precision, axis order, or spaces for a GDAL command.
