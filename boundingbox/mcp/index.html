Inspect your agent’s results on a map

BoundingBox MCP gives AI clients tools for place search, route calculations, H3 grids, and coordinate conversion. Open a sample map to see a result without installing MCP.

  • Explore a Places result

    Filter an example list and choose a place to locate its pin.

  • Inspect H3 density

  • Open a bounding box

    Inspect and export an extent around central The Hague.

Connect an MCP client

Install Node.js 18 or later. Add the bbox entry alongside any existing MCP servers, then restart or reload the client.

  • Claude Desktop uses claude_desktop_config.json.
  • Cursor uses .cursor/mcp.json.
  • Windsurf uses ~/.codeium/windsurf/mcp_config.json.
{
  "mcpServers": {
    "bbox": {
      "command": "npx",
      "args": ["-y", "bbox-mcp-server"]
    }
  }
}
VS Code with GitHub Copilot

Add this entry to .vscode/mcp.json in your workspace.

{
  "servers": {
    "bbox": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "bbox-mcp-server"]
    }
  }
}

Open a result

  1. Ask your client to generate an H3 grid around a small bounding box or find cafes near a landmark.
  2. Open the returned share_url. New H3 links can include the actual cells, with a count when the link shows a subset.
  3. To inspect a larger result, save its structured JSON or GeoJSON from your client. In BoundingBox, choose Help → Open JSON or GeoJSON result and select or drop the file. The file is read in your browser.

Supported files include Places responses, H3 cells and density, route geometry, and GeoJSON points, lines, and polygons. See the provider usage limits for live queries.
